# Vitest Tesults Reporter

Tesults is a test results reporting application. https://www.tesults.com

Vitest Tesults Reporter is a library for uploading test results to Tesults from Vitest.

## Installation

`npm install vitest-tesults-reporter --save`

## Documentation

Documentation is available at https://www.tesults.com/docs.

Vitest specific documentation: https://www.tesults.com/docs/vitest.
